# terraform-aws-secret

Creates an AWS Secrets Manager secret with an optional KMS key, optional multi-region replication, an EventBridge rule for secret events and an optional SNS topic.

Part of the [Raring Group](https://github.com/raringgroup) Terraform module library.

## Usage

```hcl
module "secret" {
  source = "git::https://github.com/raringgroup/terraform-aws-secret.git?ref=v0.1.0"

  context = module.context.self

  secret_string = "example"
}
```

Naming and tagging come from [`terraform-null-context`](https://github.com/raringgroup/terraform-null-context). Add `_context.tf` to the calling configuration and pass `context = module.context.self`.

The `modules/random-password` sub-module generates a random password and stores it in the secret.

See [`examples/`](examples/) for complete, runnable configurations (`complete`, `multi-region`, `random-password`).

### Principal inputs

`secret_read_principals`, `sns_pub_principals` and `sns_sub_principals` allow the specification of principals as well as principals with conditions. If no conditions are needed, the `condition` block can be set to `null`, but that needs to be consistent for each map item.

```hcl
{
  RootAccess = {
    type        = "AWS"
    identifiers = [var.principal_account_id]
    condition = {
      test     = null
      values   = []
      variable = null
    }
  },
  PubConditional = {
    type        = "AWS"
    identifiers = ["*"]
    condition = {
      test     = "ForAnyValue:StringLike"
      values   = [var.organization_ou_id]
      variable = "aws:PrincipalOrgPaths"
    }
  }
}
```
